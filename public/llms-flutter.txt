# befui for Flutter

> The befui components as Flutter widgets for Android and iOS: the same design as the React ones (same colour tokens, radii, sizes, dark mode and ten palettes). Copy-paste: the CLI puts one Dart file per widget in your app and from then on it is yours. No package to depend on, no Tailwind, no React.

## Setup
- `npx github:RandomKid24/befui add button --flutter` copies `lib/befui/button.dart` plus the shared files it needs (`theme.dart`, `core.dart`, `icons.dart`). Several names are allowed. Run it in the folder with your `pubspec.yaml`.
- Wire the theme once, in your `MaterialApp`: `theme: BefTheme.data()`, `darkTheme: BefTheme.data(brightness: Brightness.dark)`, `themeMode: ThemeMode.system`. Pick a palette with `BefTheme.data(palette: BefPalette.rose)` (blue, indigo, violet, rose, red, emerald, teal, amber, orange, slate).
- Browse every widget with its example: https://raw.githubusercontent.com/RandomKid24/befui/main/public/llms-flutter.txt (this file) or the Flutter section on each component page of the docs site.

## Rules
- Widgets are named `Bef<Name>` (BefButton, BefBadge) and their props mirror the React ones: `variant`, `size`, `shape` are enums (`BefButtonVariant.soft`), `loading`, `onPressed`.
- Colours come from the theme, never hard-coded: `context.bef.primary`, `context.bef.mutedForeground`, `context.bef.border` (same names as the CSS variables, camelCased). Text: `BefText.style(context, size: 14, weight: FontWeight.w500)`. Radii: `BefRadius.md`.
- Icons are our own set, painted without any package: `BefIcon(BefIcons.search, size: 16)`. Do not add an icon package.
- The font is Inter. Add it with google_fonts or as an asset and pass `fontFamily` to `BefTheme.data`; without it the platform font is used and everything still works.
- Edit the copied files freely, they belong to your app. To get the latest version of one: `add <name> --flutter --force` (overwrites your edits).
- Need a widget that has no Flutter version yet? Say so rather than rebuilding it from Material defaults: the design would drift from the React and web versions.

## Widgets

### Alert (`alert`)
Inline message in info, success, warning and danger.
- Add: `npx github:RandomKid24/befui add alert --flutter`
- Import: `import 'befui/alert.dart';` (classes: BefAlert)
- Also copies: core.dart, icons.dart, theme.dart

Example:

```dart
import 'package:flutter/material.dart';

import 'befui/alert.dart';

Widget example(BuildContext context) {
  return const Column(
    mainAxisSize: MainAxisSize.min,
    children: [
      BefAlert(title: 'Payroll locks on the 25th', child: Text('Submit attendance corrections before then.')),
      SizedBox(height: 12),
      BefAlert(variant: BefAlertVariant.success, title: 'Leave approved'),
      SizedBox(height: 12),
      BefAlert(
        variant: BefAlertVariant.warning,
        title: '3 documents expire this month',
        child: Text('Review them in the compliance tab.'),
      ),
      SizedBox(height: 12),
      BefAlert(
        variant: BefAlertVariant.danger,
        title: 'Sync failed',
        child: Text('The biometric device did not respond. Retrying in 5 minutes.'),
      ),
    ],
  );
}
```

const _team = [

  'Diya Rao',
  'Kabir Shah',
  'Meera Iyer',
  'Rohan Das',
  'Isha Nair',
  'Vikram Joshi',
];

Widget example(BuildContext context) {
  return Column(
    mainAxisSize: MainAxisSize.min,
    crossAxisAlignment: CrossAxisAlignment.start,
    children: [
      const Row(
        crossAxisAlignment: CrossAxisAlignment.end,
        children: [
          BefAvatar(name: 'Aarav Mehta', size: BefAvatarSize.xs),
          SizedBox(width: 12),
          BefAvatar(name: 'Diya Rao'),
          SizedBox(width: 12),
          BefAvatar(name: 'Kabir Shah', size: BefAvatarSize.md),
          SizedBox(width: 12),

      Wrap(
        spacing: 12,

        spacing: 12,
        runSpacing: 12,

        children: [
          BefButton(label: 'Extra small', size: BefButtonSize.xs, onPressed: () {}),
          BefButton(label: 'Small', size: BefButtonSize.sm, onPressed: () {}),
          BefButton(label: 'Medium', onPressed: () {}),
          BefButton(label: 'Large', size: BefButtonSize.lg, onPressed: () {}),

### Checkbox (`checkbox`)
Checked, unchecked and indeterminate. Works for select-all rows.
- Add: `npx github:RandomKid24/befui add checkbox --flutter`
- Import: `import 'befui/checkbox.dart';` (classes: BefCheckbox)
- Also copies: core.dart, icons.dart, theme.dart

Example:

```dart
import 'package:flutter/material.dart';

import 'befui/checkbox.dart';

Widget example(BuildContext context) {
  return StatefulBuilder(
    builder: (context, set) {
      final items = _items;
      final all = items.values.every((v) => v);
      final some = items.values.any((v) => v);
      return Column(
        mainAxisSize: MainAxisSize.min,
        crossAxisAlignment: CrossAxisAlignment.start,
        children: [
          BefCheckbox(
            value: all ? true : (some ? null : false),
            label: 'Notify me by',
            labelWeight: FontWeight.w600,
            onChanged: (v) => set(() => items.updateAll((k, _) => v)),
          ),
          for (final k in items.keys) ...[
            const SizedBox(height: 12),
            Padding(
              padding: const EdgeInsets.only(left: 24),
              child: BefCheckbox(
                value: items[k],
                label: k[0].toUpperCase() + k.substring(1),
                onChanged: (v) => set(() => items[k] = v),
              ),
            ),
          ],
        ],
      );
    },
  );
}

final _items = {'email': true, 'sms': false, 'push': false};
```

        label: 'Work email',
        child: BefInput(
          placeholder: 'you@company.com',
          keyboardType: TextInputType.emailAddress,
          leading: BefIcon(BefIcons.mail),
        ),
      ),
      const SizedBox(height: 16),
      const BefField(
        label: 'Employee ID',
        error: 'This ID is already taken.',
        child: BefInput(initialValue: 'EMP-0042', invalid: true),
      ),
      const SizedBox(height: 16),
      BefInput(placeholder: 'Search...', leading: const BefIcon(BefIcons.search), trailing: _Kbd('/')),
      const SizedBox(height: 16),
      const BefField(
        label: 'Notes',
        child: BefInput.textarea(placeholder: 'Anything the approver should know'),
      ),
      const SizedBox(height: 16),

class _Kbd extends StatelessWidget {
  const _Kbd(this.text);
  final String text;

  @override
  Widget build(BuildContext context) {
    final c = context.bef;
    return Container(
      padding: const EdgeInsets.symmetric(horizontal: 6, vertical: 1),
      decoration: BoxDecoration(
        color: c.muted,
        border: Border.all(color: c.border),
        borderRadius: BorderRadius.circular(5),
      ),
      child: Text(text, style: BefText.style(context, size: 11, color: c.mutedForeground, mono: true)),
    );
  }
