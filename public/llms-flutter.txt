# befui for Flutter

> The befui components as Flutter widgets for Android and iOS: the same design as the React ones (same colour tokens, radii, sizes, dark mode and ten palettes). Copy-paste: the CLI puts one Dart file per widget in your app and from then on it is yours. No package to depend on, no Tailwind, no React.

## Setup
- `npx github:RandomKid24/befui add button --flutter` copies `lib/befui/button.dart` plus the shared files it needs (`theme.dart`, `core.dart`, `icons.dart`). Several names are allowed. Run it in the folder with your `pubspec.yaml`.
- Wire the theme once, in your `MaterialApp`: `theme: BefTheme.data()`, `darkTheme: BefTheme.data(brightness: Brightness.dark)`, `themeMode: ThemeMode.system`. Pick a palette with `BefTheme.data(palette: BefPalette.rose)` (blue, indigo, violet, rose, red, emerald, teal, amber, orange, slate).
- Browse every widget with its example: https://raw.githubusercontent.com/RandomKid24/befui/main/public/llms-flutter.txt (this file) or the Flutter section on each component page of the docs site.

## Rules
- Widgets are named `Bef<Name>` (BefButton, BefBadge) and their props mirror the React ones: `variant`, `size`, `shape` are enums (`BefButtonVariant.soft`), `loading`, `onPressed`.
- Colours come from the theme, never hard-coded: `context.bef.primary`, `context.bef.mutedForeground`, `context.bef.border` (same names as the CSS variables, camelCased). Text: `BefText.style(context, size: 14, weight: FontWeight.w500)`. Radii: `BefRadius.md`.
- Icons are our own set, painted without any package: `BefIcon(BefIcons.search, size: 16)`. Do not add an icon package.
- The font is Inter. Add it with google_fonts or as an asset and pass `fontFamily` to `BefTheme.data`; without it the platform font is used and everything still works.
- Edit the copied files freely, they belong to your app. To get the latest version of one: `add <name> --flutter --force` (overwrites your edits).
- Need a widget that has no Flutter version yet? Say so rather than rebuilding it from Material defaults: the design would drift from the React and web versions.

## Widgets

### Accordion (`accordion`)
Collapsible sections with a smooth height animation. Single or multiple open.
- Add: `npx github:RandomKid24/befui add accordion --flutter`
- Import: `import 'befui/accordion.dart';` (classes: BefAccordionItem, BefAccordion)
- Also copies: core.dart, icons.dart, theme.dart

Example:

```dart
import 'package:flutter/material.dart';

import 'befui/accordion.dart';
import 'befui/theme.dart';

Widget example(BuildContext context) {
  return _groups(context, [
    (
      'FAQ',
      const BefAccordion(
        initiallyOpen: ['a'],
        items: [
          BefAccordionItem(
            id: 'a',
            title: 'How are leave balances calculated?',
            content: Text('Accrual runs on the first of every month, pro-rated for new joiners.'),
          ),
          BefAccordionItem(
            id: 'b',
            title: 'Can managers delegate approvals?',
            content: Text('Yes. Set a delegate for any date range from the approvals page.'),
          ),
          BefAccordionItem(
            id: 'c',
            title: 'Where is payroll data stored?',
            content: Text('Encrypted at rest, in the region you pick at signup.'),
          ),
        ],
      ),
    ),
  ]);
}

/// Labelled groups, one per kind of use.
Widget _groups(BuildContext context, List<(String, Widget)> groups) {
  final c = context.bef;
  return Column(
    mainAxisSize: MainAxisSize.min,
    crossAxisAlignment: CrossAxisAlignment.start,
    children: [
      for (var i = 0; i < groups.length; i++) ...[
        if (i > 0) const SizedBox(height: 24),
        Text(
          groups[i].$1.toUpperCase(),
          style: BefText.style(
            context,
            size: 11,
            weight: FontWeight.w500,
            color: c.mutedForeground,
            letterSpacing: 0.8,
          ),
        ),
        const SizedBox(height: 10),
        groups[i].$2,
      ],
    ],
  );
}
```

### Activity feed (`activity-feed`)
Who did what and when, grouped under Today and Yesterday, with live relative times and an optional quoted detail.
- Add: `npx github:RandomKid24/befui add activity-feed --flutter`
- Import: `import 'befui/activity_feed.dart';` (classes: BefActivity, BefActivityFeed)
- Also copies: avatar.dart, icons.dart, theme.dart

Example:

```dart
import 'package:flutter/material.dart';

import 'befui/activity_feed.dart';
import 'befui/icons.dart';
import 'befui/theme.dart';

Widget example(BuildContext context) {
  final now = DateTime.now();
  DateTime ago(double h) => now.subtract(Duration(minutes: (h * 60).round()));
  return _groups(context, [('Newest first, grouped by day', _feed(now, ago))]);
}

  return BefActivityFeed(
```

### Alert dialog (`alert-dialog`)
Confirm before something destructive. Cancel and confirm, controlled by you.
- Add: `npx github:RandomKid24/befui add alert-dialog --flutter`
- Import: `import 'befui/alert_dialog.dart';` (classes: BefAlertDialog)
- Also copies: button.dart, dialog.dart, icons.dart, theme.dart

Example:

```dart
import 'package:flutter/material.dart';

import 'befui/alert_dialog.dart';
import 'befui/button.dart';
import 'befui/icons.dart';
import 'befui/toast.dart';
import 'befui/theme.dart';

Widget example(BuildContext context) {
  return _groups(context, [('Tap to open', _trigger(context))]);
}

Widget _trigger(BuildContext context) {
  return BefButton(
    label: 'Delete employee',
    variant: BefButtonVariant.destructive,
    leading: const BefIcon(BefIcons.trash),
    onPressed: () async {
      final ok = await showBefAlertDialog(
        context: context,
        title: 'Delete this employee?',
        description: 'Their records are removed from payroll and cannot be recovered.',
        confirmLabel: 'Delete',
        destructive: true,
      );
      if (ok == true && context.mounted) BefToast.success(context, 'Employee deleted');
    },
  );
}

Widget preview(BuildContext context) {
  return BefAlertDialog(
    title: 'Delete this employee?',
    description: 'Their records are removed from payroll and cannot be recovered.',
    confirmLabel: 'Delete',
    destructive: true,
    onResult: (_) {},
  );
}

/// Labelled groups, one per kind of use.
Widget _groups(BuildContext context, List<(String, Widget)> groups) {
  final c = context.bef;
  return Column(
    mainAxisSize: MainAxisSize.min,
    crossAxisAlignment: CrossAxisAlignment.start,
    children: [
      for (var i = 0; i < groups.length; i++) ...[
        if (i > 0) const SizedBox(height: 24),
        Text(
          groups[i].$1.toUpperCase(),
          style: BefText.style(
            context,
            size: 11,
            weight: FontWeight.w500,
            color: c.mutedForeground,
            letterSpacing: 0.8,
          ),
        ),
        const SizedBox(height: 10),
        groups[i].$2,
      ],
    ],
  );
}
```

### Bottom sheet (`bottom-sheet`)
Sheet that rises from the bottom, with a drag handle to dismiss. Radix Dialog underneath.
- Add: `npx github:RandomKid24/befui add bottom-sheet --flutter`
- Import: `import 'befui/bottom_sheet.dart';` (classes: BefBottomSheet)
- Also copies: theme.dart

Example:

```dart
import 'package:flutter/material.dart';

import 'befui/bottom_sheet.dart';
import 'befui/button.dart';
import 'befui/theme.dart';
import 'befui/toast.dart';

const _options = ['Casual leave', 'Sick leave', 'Earned leave', 'Work from home'];

Widget _list(BuildContext context, ValueChanged<String> onPick) {
  final c = context.bef;
  return Column(
    mainAxisSize: MainAxisSize.min,
    crossAxisAlignment: CrossAxisAlignment.stretch,
    children: [
      for (final o in _options)
        InkWell(
          borderRadius: BorderRadius.circular(BefRadius.lg),
          onTap: () => onPick(o),
          child: Padding(
            padding: const EdgeInsets.symmetric(horizontal: 12, vertical: 12),
            child: Text(
              o,
              style: BefText.style(context, weight: FontWeight.w500, color: c.foreground),
            ),
          ),
        ),
    ],
  );
}

Widget example(BuildContext context) {
  return _groups(context, [('Tap to open', _trigger(context))]);
}

Widget _trigger(BuildContext context) {
```

```dart
ImageProvider _art(Color bg) {
  final px = Uint8List.fromList([bg.r * 255, bg.g * 255, bg.b * 255, 255].map((v) => v.round()).toList());
  return MemoryImage(_bmp(px));

Uint8List _bmp(Uint8List rgba) {
  // 1x1 24-bit BMP, stretched by Image.fit
  final b = ByteData(58);
  b.setUint8(0, 0x42);
  b.setUint8(1, 0x4D);
  b.setUint32(2, 58, Endian.little);
  b.setUint32(10, 54, Endian.little);
  b.setUint32(14, 40, Endian.little);
  b.setInt32(18, 1, Endian.little);
  b.setInt32(22, 1, Endian.little);
  b.setUint16(26, 1, Endian.little);
  b.setUint16(28, 24, Endian.little);
  b.setUint8(54, rgba[2]);
  b.setUint8(55, rgba[1]);
  b.setUint8(56, rgba[0]);
  return b.buffer.asUint8List();
}
```

```dart
  Future<void> refresh() async {
    await Future<void>.delayed(const Duration(milliseconds: 1200));
    setState(() => items = ['New update at ${TimeOfDay.now().format(context)}', ...items]);

      ),
      child: BefPullToRefresh(
        onRefresh: refresh,
        children: [
          for (final t in items)
            Container(
              padding: const EdgeInsets.symmetric(horizontal: 16, vertical: 12),
              decoration: BoxDecoration(
                border: Border(bottom: BorderSide(color: c.border)),
              ),
              child: Text(t, style: BefText.style(context, size: 13)),
```
